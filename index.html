Symbiote v4.0 Apex is a packaged AI agent runtime for Windows, Linux, and macOS with persistent memory, web automation, multi-channel messaging, and cleaner install flows. This release closes Unix-only gaps in core tooling and prepares the project for wider public deployment.

What changed in v4

  • Platform-aware shell execution for agent tools
  • Portable config, cache, credential, temp, and IPC path resolution
  • Cleaner Windows installer and launcher behavior
  • Refreshed packaged release surfaces and static HTML docs

Packaging stance

Yes — public adoption should go through a packaged npm release. v4 aligns installer assets, runtime metadata, web assets, and release notes so maintainers can publish a clean tagged release.

Why v4 matters

Fewer loose ends. Better defaults. Less platform drift.

Windows is first-class now

Core command execution and process management no longer assume Unix shells or filesystem layouts. Runtime helpers centralize shell, config, token cache, IPC, Python, and temp path resolution.

Install flows are clearer

Launchers, setup defaults, browser sidecar startup, and user-facing release guidance are aligned around the packaged Symbiote experience while preserving legacy `mach6` compatibility where needed.

Release surfaces match reality

Version metadata, docs, release notes, static landing pages, and package guidance are prepared for a maintainer-owned v4.0.0 Apex tag and publish step.

Installation

Package first. Source second. Legacy config still works.

New public installs should prefer the npm package. Existing `mach6.json` deployments remain compatible during migration.

npm package

Recommended for public usage and the cleanest release path.

npm install -g symbiote symbiote init --ui symbiote start
Source install

Best when you want local development or repository-level customization.

git clone https://github.com/artifact-opensource/symbiote.git cd symbiote npm install npm run build node dist/index.js version
