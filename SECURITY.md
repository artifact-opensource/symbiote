# Security Policy

## Supported Versions

The project currently supports the latest released version and the latest code on the `master` branch.

| Version | Supported |
| ------- | --------- |
| Latest `master` | Yes |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Instead, report the issue privately through one of the following methods:

- GitHub Security Advisories: use the repository's Security tab and click "Report a vulnerability"
- Email: security@artifact-opensource.github.io

When reporting, include:
- a description of the vulnerability and affected component
- steps to reproduce or a proof of concept
- impact and severity
- any suggested mitigation or fix

We will acknowledge receipt within 5 business days and work toward a resolution as quickly as possible.

## Disclosure Policy

- Please allow a reasonable amount of time for investigation and remediation before public disclosure.
- We may coordinate with you on an appropriate disclosure timeline.
- Once a fix is available, we may publish a security advisory.

## Response Expectations

- Triage: within 5 business days
- Initial assessment: within 10 business days
- Remediation timeline: depends on severity and complexity

If you are unsure whether an issue qualifies as a security bug, please contact us privately before exposing it publicly.
